## 🧠 My Problem-Solving Approach

1. Understand the problem and its requirements.
2. Identify the input, expected output, and important conditions.
3. Break the problem into smaller steps.
4. Develop a simple solution using Python.
5. Test the code with different inputs and edge cases.
6. Improve the solution using built-in functions or a more efficient approach.
7. Save and organize the final code for future reference.
